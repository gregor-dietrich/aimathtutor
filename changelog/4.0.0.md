# AIMathTutor Changelog — Version 4.0.0

## Added

- Added a dedicated permission for managing AI configurations.

## Changed

- Improved system performance and loading times when viewing large collections of data.

## Security

- Enhanced protection against Server-Side Request Forgery (SSRF) by re-validating AI provider URLs against the configured host allow-list immediately before every outbound request, closing the time-of-check/time-of-use gap (including DNS-rebinding) that previously existed between admin save and dispatch. The same check now also covers connectivity tests, Ollama health/model probes, and the Google/OpenAI generators.
- Added HTTP response headers `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, and `Strict-Transport-Security` to defend against clickjacking, MIME sniffing, and TLS downgrade.
- The session cookie is now marked `SameSite=Lax`, reducing exposure to cross-site request forgery.
- The auto-generated encryption-at-rest master-key file is now protected with owner-only filesystem permissions on every supported OS: POSIX `0600` where available, with a Windows ACL fallback. Startup now fails fast if neither mechanism can be applied, rather than silently writing the key with default permissions.
