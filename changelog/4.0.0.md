# AIMathTutor Changelog — Version 4.0.0

## Added

- Added a dedicated permission for managing AI configurations.

## Changed

- Admin grids load faster with large amounts of data.
- The admin dashboard loads faster with large amounts of data.
- Admin permission checks are cached for improved performance.
- Improved feedback and error messages for expired sessions.
- Improved AI response processing and error handling.

## Fixed

- Resolved bug where editing a user would clear their activation key.

## Security

- User bans and deactivations enforced immediately.
- Enhanced protection against automated login attempts.
- Production environments enforce use of non-default database passwords.
- Strengthened SSRF protections by re-checking every AI provider request against configured allow-list.
- Added clickjacking, MIME-sniffing, referrer-leak, and TLS-downgrade protections via standard HTTP security headers.
- Hardened the session cookie against cross-site request forgery via the `SameSite` attribute.
- Improved protection of the encryption-at-rest master key on non-POSIX platforms.
- Hardened internal encryption error handling.
- Upgraded internal key derivation to HKDF-SHA256 (RFC 5869).
