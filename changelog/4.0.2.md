# AIMathTutor Changelog — Version 4.0.2

## Changed

- Search now matches the `%` and `_` characters literally instead of treating them as wildcards.
- Rank names are trimmed and their internal whitespace collapsed before saving, and a rank can no longer be created or updated with a blank name.

## Fixed

- The "completed" badge now reliably appears for finished exercises on the lessons overview page.

## Security

- AI provider configuration changes are now authorized before any value validation or network lookups are performed.
- Pinned React Router to 7.15.0 to address remote code execution, cross-site scripting, and denial-of-service vulnerabilities (CVE-2026-33244, CVE-2026-33245, CVE-2026-34077, CVE-2026-40181, CVE-2026-42211, CVE-2026-42342)
- Pinned Netty to 4.1.135.Final to address an IPv6 subnet filter bypass and a memory leak (CVE-2026-44249, CVE-2026-44893)
