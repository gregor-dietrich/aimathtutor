# AIMathTutor Changelog — Version 4.0.13

## Changed

- Quarkus platform version updated from 3.33.3.3 to 3.33.4

## Security

- Pinned Jackson 3 to 3.1.7 to address a denial of service via oversized duration and calendar
  values, unrestricted URI schemes when reading file paths, and an incomplete denylist of unsafe
  polymorphic base types (CVE-2026-68497, CVE-2026-19032, CVE-2026-83557), plus unbounded type id
  cache growth and quadratic forward-reference resolution (CVE-2026-91776, CVE-2026-91777)
