# AIMathTutor Changelog — Version 4.0.8

## Changed

- Quarkus platform version updated from 3.33.2.1 to 3.33.3
- Vaadin version updated from 25.2.3 to 25.2.5

## Security

- Removed the pinned version overrides for Jackson, Netty and the PostgreSQL JDBC driver.
  The updated Quarkus platform now ships the fixed versions itself, so the overrides no
  longer changed anything and the previously addressed vulnerabilities remain fixed.
