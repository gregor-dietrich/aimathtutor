# AIMathTutor Changelog — Version 3.1.0

## Added

- Support for configuring trusted reverse proxy IP addresses via the `app.security.trusted-proxy-ips` property for deployments behind load balancers.

## Security

- Password validation now explicitly enforces a 72-byte limit to ensure safe processing by the hashing algorithm.
- Mitigated User Lockout DoS vulnerability by implementing a composite rate-limiting key (username:clientIp) in the authentication process.
- Eliminated potential user impersonation (IDOR) in exercise creation.
- Exercise and Lesson services now strictly sanitize all user-provided HTML content.
- Eliminated potential SQL injection vulnerability in the comment system's rate limiting logic.
- Extended timing attack protections during login to fully cover early-exit paths (e.g., when an account is banned or not activated).
