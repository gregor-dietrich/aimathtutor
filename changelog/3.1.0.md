# AIMathTutor Changelog — Version 3.1.0

## Added

- The AI tutor can now render mathematical expressions in chat messages.

## Security

- Password validation now explicitly enforces a 72-byte limit to ensure safe processing by the hashing algorithm.
- Mitigated User Lockout DoS vulnerability.
- Eliminated potential user impersonation (IDOR) in exercise creation.
- Exercise and Lesson services now strictly sanitize all user-provided content.
- Improved comment system's rate limiting logic.
- Extended timing attack protections during login .
- Support for configuring trusted reverse proxy IP addresses via the `app.security.trusted-proxy-ips` for deployments behind load balancers.
- Standardized all application-specific configuration to a unified `app.` property schema (e.g., `app.google.api.key`, `app.security.encryption-key-file`).
- Mitigated TOCTOU SSRF vulnerability by implementing a mandatory hostname allow-list (`app.security.allowed-ollama-hosts`) for Ollama API validation.
