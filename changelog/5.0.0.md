# AIMathTutor Changelog — Version 5.0.0

## Added

- Database schema is created and upgraded automatically on startup.

## Changed

- New installations no longer contain demo lessons, exercises, sessions or teacher/student accounts.
- New installations no longer contain an `admin` account with the password `admin`. The first admin account is
  created on the first start from the `APP_BOOTSTRAP_ADMIN_USERNAME` (default `admin`) and
  `APP_BOOTSTRAP_ADMIN_PASSWORD` settings; without a password, the application refuses to start.

## Upgrade Notes

- Upgrade to the latest 4.0.x first. Its database is adopted automatically without manual SQL. Databases from older
  releases must be brought to the 4.0.x schema before upgrading.
- The database no longer needs an initialization script. Remove the `docker-entrypoint-initdb.d` mount from existing
  Docker Compose files: if the database volume is ever recreated while it is still mounted, the old script creates the
  former demo accounts with their publicly known passwords.
- If the `admin` account still has the password `admin`, the application refuses to start until
  `APP_BOOTSTRAP_ADMIN_PASSWORD` is set, and then replaces that password once. Accounts with any other password are not
  affected. Remove the setting after the first successful start.
