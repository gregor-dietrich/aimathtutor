# AIMathTutor Changelog — Version 4.0.11

## Changed

- Quarkus platform version updated from 3.33.3.1 to 3.33.3.2
- Vaadin version updated from 25.2.6 to 25.2.7

## Security

- Pinned Netty to 4.1.138.Final to address an SNI routing bypass via fragmented TLS
  ClientHello, quadratic pre-handshake reassembly in SNI parsing, and cache poisoning via a
  CORS Vary header overwrite (CVE-2026-75595, CVE-2026-75596, CVE-2026-59903), plus a batch of
  request-smuggling, header-validation, resource-exhaustion and memory-leak fixes in the
  HTTP/1.1, HTTP/2, SPDY, SMTP, MQTT, Redis and HAProxy codecs and in OCSP certificate
  validation (CVE IDs not yet assigned)
