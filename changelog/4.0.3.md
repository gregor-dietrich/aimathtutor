# AIMathTutor Changelog — Version 4.0.3

## Changed

- Usernames are now trimmed and stored in lower case when creating or editing users, and duplicate checks ignore case.
- Lessons can no longer be set as their own parent.
- Quarkus platform version updated from 3.33.2 to 3.33.2.1
- Vaadin version updated from 25.1.6 to 25.1.8

## Fixed

- Admin user search now finds users by email addresses containing `_`, `!` or `%`.
- Searching student progress by a term containing `@` now performs an exact email lookup instead of returning no results.
- Opening a different exercise from an already open exercise workspace no longer duplicates the page content or starts an extra session.
- The admin password-change dialog now shows an error when the two password fields do not match, instead of doing nothing.
- Removed the non-functional "Ollama API timeout in seconds" entry from the AI configuration settings.

## Security

- Removed pinned version overrides for netty, postgres and react-router dependencies
