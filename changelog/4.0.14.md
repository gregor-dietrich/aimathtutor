# AIMathTutor Changelog — Version 4.0.14

## Fixed

- Admin forms show why a save was rejected, such as a username that is already taken, instead of "Unexpected error
  occurred"
- `make password` hashes the whole password when it contains a space, not just its first word, and no longer
  passes the password on the Maven command line
- The password length message names the real maximum of 72 characters instead of 100

## Security

- Updated DOMPurify from 3.4.15 to 3.4.16 to address event handlers left active on content
  removed during in-place sanitization (GHSA-p98j-92pf-mc4p)
- Saving a user no longer makes them an administrator when their selected rank was deleted while the user form was
  open; the save is rejected instead
- The last active administrator can no longer be deleted, banned, deactivated or demoted, including by removing
  permissions from their rank, so the admin area can't be locked out
