# AIMathTutor Changelog — Version 4.0.14

## Changed

- Vaadin version updated from 25.3.0 to 25.3.1

## Fixed

- Admin forms show why a save was rejected, such as a username already taken, instead of
  "Unexpected error occurred"
- `make password` hashes the whole password when it contains a space, and no longer passes it on
  the Maven command line
- Passwords longer than 72 characters are refused with a message that names the 72-character limit
- A release can no longer replace its multi-platform images with a single-platform or stale image

## Security

- Updated DOMPurify from 3.4.15 to 3.4.16 to address event handlers left active on content
  removed during in-place sanitization (GHSA-p98j-92pf-mc4p)
- Updated source-map-js, used by the frontend build, from 1.2.1 to 1.2.2 to address a denial of
  service through crafted source maps (GHSA-68fv-2mgg-jv7q)
- Users who manage users or ranks can no longer grant more permissions than their own rank has,
  or change, reset the password of or delete a user or rank above their own
- The last active administrator can no longer be deleted, banned, deactivated or demoted. Only an
  active user whose rank has every permission counts as an administrator: if the Admin rank lost a
  permission before upgrading, restore it with the README's "Recovering administrator access" steps
- Changes made at the same moment can no longer leave no active administrator
- Saving a user whose selected rank was deleted in the meantime is rejected instead of making them
  an administrator
- A production build refuses to start with the `dev` or `test` profile, or with Hibernate schema
  management set to anything but `validate` or `none`; both used to delete all data. Remove the
  setting from the deployment, and never re-run `init.sql` on a database that holds data
- Changing a password ends the account's other sessions
- Banned, deactivated or deleted users lose their rank's permissions at once, including on pages
  already open, and are signed out on their next page change
- Changing one's own password allows at most 5 attempts per 15 minutes in each session
- One's own password can only be changed on the Settings page, which asks for the current one
- An open page stays tied to its own account, so it can't act as a later account given the same
  username
