# AIMathTutor Changelog — Version 4.0.7

## Changed

- Vaadin version updated from 25.2.1 to 25.2.3

## Security

- Pinned Netty to 4.1.136.Final to address denial-of-service, memory-leak, CORS bypass and
  header-injection vulnerabilities in the HTTP, HTTP/2, DNS, SPDY and HAProxy codecs
  (CVE-2026-55831, CVE-2026-55833, CVE-2026-55851, CVE-2026-56745, CVE-2026-56746,
  CVE-2026-59898, CVE-2026-59899, CVE-2026-59900, CVE-2026-59901, CVE-2026-59919,
  CVE-2026-59921, plus a DNS record decoder memory leak with no assigned CVE)
- Pinned the PostgreSQL JDBC driver to 42.7.12 to address a silent channel-binding
  authentication downgrade via an unsupported certificate type (CVE-2026-54291)
