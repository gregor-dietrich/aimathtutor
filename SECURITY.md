# Security

## Reporting a Vulnerability

**Please do _not_ report security vulnerabilities through public GitHub
issues.**

Instead, [report it privately](https://github.com/Carpenter-Softworks/Workshop/security/advisories/new).

## Supported Versions

Only the latest stable release receives security patches. Older versions should
be upgraded promptly.

## Process

We aim to acknowledge your report within 48 hours, and to triage within 5
business days. Once a fix is ready, we'll coordinate a disclosure date with
you.

## Acknowledgments

We thank contributors who responsibly disclose vulnerabilities, and will
credit you in the advisory unless you'd prefer to stay anonymous.
